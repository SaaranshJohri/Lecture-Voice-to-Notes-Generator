🎙️ Lecture Voice-to-Notes Generator

An AI-powered system that automatically converts lecture audio into structured notes, concise summaries, quizzes, and an interactive doubt-solving chatbot.

This project leverages state-of-the-art speech recognition, natural language processing, and generative AI to help students efficiently understand and revise recorded lectures.

🚀 Features

Speech-to-Text Transcription using OpenAI Whisper

Text Cleaning & Sentence Segmentation with spaCy

Automatic Lecture Summarization using Transformer-based NLP models

Quiz Generation from key concepts to reinforce learning

AI Chatbot (Gemini API) for real-time doubt solving

Interactive Streamlit Frontend with a clean, dark-themed UI

Downloadable Notes for offline study

🛠️ Tech Stack

Language: Python

Speech Recognition: OpenAI Whisper

NLP & Summarization: spaCy, Hugging Face Transformers, NLTK

Quiz Generation: KeyBERT + NLP-based question formation

Chatbot: Google Gemini API

Frontend: Streamlit

Deployment: Streamlit Cloud

Academic note automation

Interview and seminar summarization
